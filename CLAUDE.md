# Проект avtostavka

Два независимых бота:

- `avtostavka/` — пакет value-беттинга (стратегия, стейкинг, риск, бэктест, paper-режим).
  Тесты: `python -m unittest -v`.
- `dbbet/autobet_bot.py` — рабочий бот пользователя: Telegram + Playwright через CDP
  к Opera, ставки на DB Bet (лайв настольный теннис «Лига Про» и FIFA-пенальти)
  по сигналам из Telegram-каналов, система догона. Сайт работает через зеркала
  (`/mirror` в боте), доступ через VPN Opera. Третья игра — 🃏 21 очко (`g21`): сигналы
  `AUTO21` из отдельного канала (формат — `dbbet/SIGNAL21.md`), рынки Голд/Раздача,
  лесенки `G21_LADDERS`, ставка урезается до лимита купона.

- `vlad/vlad_21ochko_bot.py` — бот-персонаж «Влад» в чате «21 очко»: считает сигналы 21GROX
  (`process_grox`) и дублирует линии Голд/Раздача в канал автоставки строками `AUTO21`
  (`auto21_*`, канал `AUTO21_CHANNEL`).

Правила:
- Отступ в `dbbet/autobet_bot.py` — 2 пробела, комментарии и сообщения на русском.
- Никаких секретов в репозитории: токены, ключи API, логин/пароль — только через переменные
  окружения / `dbbet/autobet.env` (в .gitignore). У пользователя личные копии с вписанными данными.
- Бот должен держать одну вкладку DB Bet (`fresh_page`/`adopt_tab`/`close_extra_tabs`).
- Браузер: `state["browser_mode"]` own (свой Chromium, `launch_own_browser`, прокси
  `AUTOBET_PROXY`) или opera (CDP). Зависание: сторож `watchdog_loop` убивает свой браузер
  (`kill_own_browser` — только процессы chrome с этим --user-data-dir) или перезапускает бота.
- Каждое обновление бота — поднять `BOT_VERSION`, пользователь сверяет её при запуске.
- Пользователь общается на русском.

Планы (договорились с пользователем):
- Теннис перевести на служебный канал со строгим форматом сигналов, по аналогии с AUTO21.
- Отдельная статистика по 21 очко в отчёте — пользователь отложил.
