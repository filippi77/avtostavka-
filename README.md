# Бот прогнозов на масти (баккара)

Игровой Telegram-бот для чата: игроки ставят игровые фишки на следующие раздачи,
а бот сам рассчитывает ставки по постам канала статистики
(`#N207. 7(J♦️ 7♣️) - ✅9(2♦️ 7♥️) #T16 🔵 #R`).

## Что умеет

- `/bet 208 ♥ 50` — в картах **игрока** в игре #N208 будет черва (×1.9)
- `/bet 208 игрок 50`, `банкир`, `ничья` — исход раздачи (×1.95 / ×1.95 / ×8)
- масти можно писать словами: `пики`, `крести`, `черви`, `буби`
- `/balance`, `/bonus` (бонус раз в неделю), `/top` (рейтинг)
- `/buy` — купить фишки за **Telegram Stars** (в личке с ботом)
- `/give 500` — админ: начислить/списать обычные фишки ответом на сообщение игрока

Ставки на игру закрываются, как только в канале появился её пост (даже с ⏰).
Ставки, которые не рассчитались за `BET_TTL_HOURS`, возвращаются.

## Кнопки ставок в чате

Как только в канале появляется пост игры N (игра пошла или уже закончилась),
бот сразу выкладывает в чат карточку игры N+1 с кнопками: масти ♠ ♣ ♥ ♦,
игрок / банкир / ничья, сумма 💰 10 / 50 / 100 / 500, кошелёк 🏆 Турнир /
Обычные фишки, 📊 Рейтинг и 👤 Мой кабинет. Ставить можно, пока идёт игра N.
Как только появился пост игры N+1, кнопки убираются — поставить во время
самой игры нельзя.

Это работает точно, если канал публикует пост в начале игры (с ⏰) и потом
дописывает итог. Если канал пишет пост только после конца игры, включите
`BET_WINDOW_SECONDS` — тогда приём закроется по таймеру.

Кнопки мастей подписаны словами: ♠ Пики, ♣ Крести, ♥ Черви, ♦ Буби. Под карточкой одна кнопка «🎯 Сделать ставку»: она открывает личку с ботом, где игрок видит масти или исход, сумму и кошелёк. Выбор никому в чате не виден; ставка записывается на карточку в основном чате. Сумма и кошелёк запоминаются за каждым игроком; подтверждение ставки и
рейтинг видит только нажавший (всплывающее окно), в чат ничего не пишется.
Частота карточек — каждая игра / раз в 5 / раз в 10 / выкл — в панели `/admin`.

## Кабинет игрока

В личке с ботом внизу всегда есть кнопки: 💰 Мой баланс, 🎁 Бонус (300 фишек
раз в 7 дней), 📊 Рейтинг, 🏆 Турнир, ⭐ Купить фишки, ❓ Как играть.

## Подписка на канал

Если указан `REQUIRED_CHANNEL`, ставить, брать бонус и вступать в турнир
можно только подписчикам канала. Неподписанным бот показывает кнопки
«Подписаться» и «Я подписался». Бота нужно сделать админом этого канала —
иначе Telegram не даёт ему проверять подписчиков (тогда проверка пропускается).

## Турнир

Турнир запускает админ из панели `/admin` на 1, 3 или 7 дней. Каждому
участнику выдаётся 1000 **турнирных** фишек — их нельзя купить или получить
бонусом. Побеждает тот, у кого к концу турнира больше всего турнирных фишек.

- `/tournament` — вступить, посмотреть правила, призы и таблицу
- `/tbet 209 ♥ 50` или кнопки карточки с выбранным «🏆 Турнир» — турнирная ставка (до 500)
- для приза нужно сделать минимум 20 ставок
- по окончании бот объявляет первые места в чате, а админам присылает в личку
  список победителей с @username. Призы (по умолчанию 200 / 100 / 50 ⭐)
  отправляете вы сами — бот не умеет переводить звёзды

У победителей ничего не списывается: это розыгрыш на бесплатных фишках,
а не обмен фишек на подарки.

## Дуэли ⚔️

Ответом на сообщение соперника `/duel 500` (без ответа — открытый вызов для
всех). Длину — 1, 3, 5 или 10 игр (`DUEL_GAME_OPTIONS`) — вызывающий выбирает
кнопками в вызове или сразу: `/duel 500 3`. После «Принять» у обоих замораживается ставка, и игры подряд
каждый выбирает масть игрока кнопками под сообщением дуэли. Выбор соперника
скрыт до начала игры, потом раскрывается. Кто угадал больше — забирает обе
ставки, ничья — ставки возвращаются. Только обычные фишки. Вкл/выкл и анонс
с правилами — в `/admin`.

## Актив недели 🔥 и раздачи 🎁

**Актив недели** — очки за действия в чате: сообщение от 3 слов (не чаще раза
в минуту, чтобы спам не окупался) — 1, ответ другому участнику — ещё 1,
ставка — 1, дуэль — 3. Таблица — `/active` или кнопка «🔥 Актив» в кабинете.
В воскресенье в 23:59 бот объявляет топ-3 в чате, а админам присылает список
для призов (по умолчанию 100 / 50 / 25 ⭐, `ACTIVITY_PRIZES`; минимум
`ACTIVITY_MIN_POINTS` очков).

**Раздачи** — `DROPS_PER_DAY` раз в день в случайное время с `DROP_HOURS`
бот пишет в чат «🎁 Первые 3, кто нажмёт, получат по 300 фишек». В `/admin`:
вкл/выкл, «🎁 Раздача сейчас» и «⭐ Звёздная раздача» — первый нажавший
получает звёзды от владельца (бот пришлёт, кому отправить).

## Быстрые команды в меню «/»

Бот сам заполняет своё меню команд. В группах — быстрые ставки на ближайшую
игру суммой с карточки: баккара `/hearts` `/spades` `/clubs` `/diamonds`
`/player` `/banker` `/tie`, пенальти `/p1` `/p2` `/over` `/under`, плюс
`/duel` и `/top`. Сообщение с командой бот удаляет (нужно право удалять
сообщения), ответ присылает в личку; если личка не открыта — коротко отвечает
в чате и через 8 секунд удаляет ответ. В личке меню — кабинет. Команды других
ботов в чате убрать нельзя — только удалив ненужных ботов из группы.

## Закрытие ставок раньше игры на сайте

Канал публикует результаты с задержкой, поэтому игра на сайте уже идёт, когда
в статистике ещё нет её поста. Чтобы нельзя было поставить на идущую игру, ставки
на следующую игру закрываются **по таймеру через N секунд после поста предыдущей**
(`BET_WINDOW_SECONDS`, по умолчанию 30). В `/admin` значение переключается кнопками
20 / 30 / 45 / 60 / Выкл — подберите его по реальной задержке канала.
`MAX_GAMES_AHEAD=1` разрешает ставки только на ближайшую игру.

## Сброс балансов

`/admin` → «♻️ Сбросить балансы»: у всех, кто не покупал фишки за звёзды, обычный
баланс = `RESET_AMOUNT` (5000). **Покупатели остаются с тем, что у них есть.**
Перед сбросом бот сохраняет копию базы рядом с файлом (`suitbot.sqlite3.bak-…`).
Открытые ставки и дуэли отменяются без выплат; у покупателей замороженные фишки
возвращаются. Турнирные фишки и ставки, значки, VIP и звания остаются.

## Как выглядит карточка

> 🎴 **#N320** · 🟢 ставки открыты
> ▓▓▓▓▓▓▓▓ Ставок: 22
> ♠ 27% ♣ 18% ♥ 41% ♦ 14%

Полоска показывает заполненность игры, проценты — долю ставок по мастям (суммы
не видны). После начала игры статус становится 🔴. В личке при ставке отмечены
текущие сумма и кошелёк ✓ и показано, что уже поставлено. Итог игры — одной
строкой, 🔥 при выигрыше от 1 000 фишек. В рейтинге полоска показывает отставание
от лидера.

## Магазин 🛒

В личке с ботом — кнопка «🛒 Магазин»: товар → экран «Купить за …?» → «✅ Купить».

| Товар | Цена | Срок |
|---|---|---|
| ✨ Значок у имени во всех сообщениях бота | 1 000 | навсегда |
| 🏷 Звание в чате (готовое) | 10 000 | 7 дней |
| ✍️ Своё звание (до 16 символов, без эмодзи) | 15 000 | 7 дней |
| 💼 VIP — ставки до 100 000 | 5 000 | 7 дней |
| 🎰 Лишняя попытка крутилки | 100 | одна |

Звание — подпись администратора в Telegram: бот назначает игрока админом только
с правом приглашать по ссылке и снимает права, когда срок вышел. Боту нужно право
назначать админов. Если выдать звание не вышло, фишки возвращаются. Цены — `SHOP_*`
в настройках, магазин открывается и закрывается в `/admin`.

## Крутилка 🎰

Раз в сутки бесплатно, кнопка «🎰 Крутить» в кабинете. Результат выбирает сам
Telegram (анимированный слот): 777 → 1000, три одинаковых → 300, две → 50,
иначе 10 фишек (`SPIN_PRIZES`).

## Режим пенальти (`GAME=penalty`)

Тот же бот ведёт чат FIFA Penalty. Канал публикует серии заранее:
`⏳ #N44` · `Манчестер Сити (0:0) Ювентус` · `П1 1.92 | П2 1.89` · `ТБ 4.5 1.66 | ТМ 4.5 2.09`.
Бот сразу выкладывает карточку серии с кнопками П1 / П2 и ТБ / ТМ — коэффициенты
из поста. Ставки закрываются, как только серия началась (счёт уже не 0:0) или
закончилась предыдущая (`PENALTY_CLOSE_ON_PREV_FINISH`). Итог — по посту с 🏁.
Команды: `/bet 45 п1 50`, `/bet 45 тб 50`. В дуэлях выбирают победителя серии.
Турнир, крутилка, рейтинг, магазин, языки и панель — как в баккаре.

## Язык: русский / O'zbekcha

Всё, что видят игроки (карточки, кнопки, кабинет, ставки, дуэли, турнир,
объявления), переводится на узбекский (латиница). Переключатель «🌐 Язык» —
в `/admin`, язык по умолчанию — `BOT_LANG`. Панель админа остаётся на русском.
Команды понимают и узбекские слова: `/bet 208 o'yinchi 50`, масти `chillak`,
`g'isht`, `chirvo`, `qarg'a`. Тексты лежат в `suitbot/i18n.py` — их стоит
показать носителю языка.

## Панель управления `/admin`

Пишется боту в личку, работает только для id из `ADMINS` (свой id: `/id`).

- выбранный чат, последняя игра канала, статус турнира и число участников
- ▶️ запустить турнир на 1 / 3 / 7 дней, 📊 таблица, ⏹ завершить досрочно
- частота карточек: каждая игра / раз в 5 / раз в 10 / выкл
- 📢 отправить в чат приглашение с кнопкой «Начать играть» и закрепить его
- 🎁 выдать всем фишки: обычные всем игрокам или турнирные всем участникам турнира,
  с подтверждением и (по желанию) объявлением в чате; любая сумма — `/giveall 2000`,
  `/giveall турнир 300`

Основной чат выбирается командой `/setchat`, которую админ пишет в нужной группе.

## Как игроки попадают в бота

Отдельной регистрации нет: аккаунт с 500 фишками создаётся при первом
обращении — по кнопке «Начать играть» (ссылка `t.me/<бот>?start=join`), по
любой команде или по нажатию кнопки на карточке в чате. Ссылку на бота можно
давать где угодно: в закрепе чата, в описании канала, в постах.

## Важно про Stars

Telegram позволяет боту **принимать** Stars, но не позволяет **выплачивать** их
игрокам (кроме возврата конкретного платежа). Поэтому здесь Stars — это только
покупка фишек, а фишки нельзя вывести. Это ещё и держит бота подальше от
азартных игр на реальные деньги: проверьте правила Telegram для Stars и законы
своей страны, прежде чем добавлять любые призы с реальной ценностью.

## Запуск

1. Создайте бота у [@BotFather](https://t.me/BotFather), возьмите токен.
2. В BotFather выключите privacy mode (`/setprivacy` → Disable) — иначе бот не
   увидит посты канала в группе. Либо сделайте бота админом группы.
3. Добавьте бота в чат, который привязан к каналу статистики (посты канала
   приходят туда автопересылкой).
4. Узнайте id канала (вида `-100…`) и укажите его в `RESULT_SOURCES`.
5. Напишите боту `/id`, впишите свой id в `ADMINS`, перезапустите бота.
6. В группе напишите `/setchat`, затем в личке с ботом откройте `/admin`.
   Чтобы бот мог закрепить приглашение, дайте ему в группе право закреплять сообщения.

```bash
python3 -m venv .venv
.venv/bin/pip install -r requirements.txt
cp .env.example .env   # заполните BOT_TOKEN и остальное
set -a; . ./.env; set +a
.venv/bin/python -m suitbot.bot
```

Тесты: `.venv/bin/pip install pytest && .venv/bin/python -m pytest`

### На сервере (Linux, постоянно)

```bash
sudo mkdir -p /opt/suitbot && cd /opt/suitbot   # распакуйте сюда архив
python3 -m venv .venv && .venv/bin/pip install -r requirements.txt
sudo cp deploy/suitbot.service /etc/systemd/system/
sudo systemctl daemon-reload && sudo systemctl enable --now suitbot
journalctl -u suitbot -f   # логи
```

База данных — файл `suitbot.sqlite3` в папке бота: его стоит иногда копировать в бэкап.

## Настройки

Все настройки задаются через переменные окружения, см. `.env.example`.
`GAME_NUMBER_WRAP` — номер, после которого счётчик игр начинается заново.
Проверьте его по своему каналу: от него зависит, на какие игры принимаются ставки.
