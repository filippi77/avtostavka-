# Автоставка — приложение курьера

Мобильное веб‑приложение (PWA) для доставки посылок:

1. **Сканирование этикетки** — фотографируете посылку камерой телефона, текст распознаётся прямо на устройстве (Tesseract.js, русский + английский).
2. **Выделение адреса** — из текста автоматически берётся адрес получателя (метки «Куда:», «Адрес получателя:» или эвристика по «ул.», «д.», «г.», индексу), адрес отправителя отбрасывается, телефон получателя подставляется отдельно. Адрес можно поправить вручную.
3. **Поиск на карте** — геокодирование через OpenStreetMap (Nominatim). Если вариантов несколько — выбираете нужный; если адрес не найден — ставите точку на карте пальцем. Маркеры можно перетаскивать.
4. **Список доставок** — номера по порядку объезда, отметка «Доставлено», звонок получателю, заметки, ручная перестановка.
5. **Оптимальный маршрут** — порядок объезда считается по реальному времени в пути (OSRM) от вашего текущего местоположения (GPS), затем улучшается алгоритмами 2‑opt / or‑opt. Если сервер маршрутов недоступен — расчёт по прямым расстояниям.
6. **Навигатор** — маршрут или одна точка открываются в Яндекс Картах / Навигаторе, Google Maps или 2ГИС.

Список хранится в памяти телефона (localStorage) и не теряется при закрытии.

## Установка на телефон

Камера и GPS в браузере работают только по **HTTPS**, поэтому приложение нужно разместить на хостинге. Проще всего — GitHub Pages:

1. Влейте код в ветку `main`.
2. В репозитории: **Settings → Pages → Build and deployment → Source: GitHub Actions**.
3. После деплоя откройте адрес вида `https://<логин>.github.io/avtostavka-/` на телефоне.
4. **Android (Chrome):** меню ⋮ → «Добавить на главный экран» / «Установить приложение».
   **iPhone (Safari):** «Поделиться» → «На экран „Домой“».

Приложение откроется во весь экран, как обычное.

## Локальный запуск

```bash
npm start      # http://localhost:8080 (на localhost камера тоже работает)
npm test       # тесты разбора адресов и оптимизации маршрута
```

Сборка не нужна — это статические файлы.

## Советы по сканированию

- Снимайте этикетку ровно, крупно, при хорошем освещении — блок адреса должен занимать бо́льшую часть кадра.
- Первое распознавание дольше (загружается модель ~15 МБ), дальше она берётся из кэша.
- Если город на этикетках часто не пишут — укажите «Город по умолчанию» в настройках ⚙.
- Включите «Добавлять сразу, если адрес найден однозначно», чтобы сканировать посылки подряд без лишних нажатий.

## Структура

| Файл | Назначение |
|---|---|
| `index.html`, `css/app.css` | интерфейс |
| `js/app.js` | логика приложения: список, карта, диалоги, настройки |
| `js/ocr.js` | подготовка фото и распознавание текста |
| `js/address.js` | извлечение адреса/телефона из текста, нормализация для геокодера |
| `js/geocode.js` | поиск координат (Nominatim) |
| `js/route.js` | матрица времени (OSRM), оптимизация порядка, геометрия маршрута |
| `sw.js`, `manifest.webmanifest` | установка как приложение и офлайн‑кэш |

## Ограничения бесплатных сервисов

Используются публичные серверы OpenStreetMap: Nominatim (не чаще 1 запроса в секунду) и демо‑сервер OSRM (до ~100 точек). Для рабочей нагрузки многих курьеров их стоит заменить на собственные инстансы или коммерческие API (Яндекс Геокодер / Маршрутизатор, 2ГИС, Google) — это меняется в `js/geocode.js` и `js/route.js`.
