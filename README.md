# Бот прогнозов на масти (баккара)

Игровой Telegram-бот для чата: игроки ставят игровые фишки на следующие раздачи,
а бот сам рассчитывает ставки по постам канала статистики
(`#N207. 7(J♦️ 7♣️) - ✅9(2♦️ 7♥️) #T16 🔵 #R`).

## Что умеет

- `/bet 208 ♥ 50` — в картах **игрока** в игре #N208 будет черва (×1.9)
- `/bet 208 игрок 50`, `банкир`, `ничья` — исход раздачи (×1.95 / ×1.95 / ×8)
- масти можно писать словами: `пики`, `крести`, `черви`, `буби`
- `/balance`, `/bonus` (ежедневный бонус), `/top` (лидеры)
- `/buy` — купить фишки за **Telegram Stars** (в личке с ботом)
- `/give 500` — админ: начислить/списать фишки ответом на сообщение игрока

Ставки на игру закрываются, как только в канале появился её пост (даже с ⏰).
Ставки, которые не рассчитались за `BET_TTL_HOURS`, возвращаются.

## Важно про Stars

Telegram позволяет боту **принимать** Stars, но не позволяет **выплачивать** их
игрокам (кроме возврата конкретного платежа). Поэтому здесь Stars — это только
покупка фишек, а фишки нельзя вывести. Это ещё и держит бота подальше от
азартных игр на реальные деньги: проверьте правила Telegram для Stars и законы
своей страны, прежде чем добавлять любые призы с реальной ценностью.

## Запуск

1. Создайте бота у [@BotFather](https://t.me/BotFather), возьмите токен.
2. В BotFather выключите privacy mode (`/setprivacy` → Disable) — иначе бот не
   увидит посты канала в группе. Либо сделайте бота админом группы.
3. Добавьте бота в чат, который привязан к каналу статистики (посты канала
   приходят туда автопересылкой).
4. Узнайте id канала (вида `-100…`) и укажите его в `RESULT_SOURCES`.

```bash
python3 -m venv .venv
.venv/bin/pip install -r requirements.txt
cp .env.example .env   # заполните BOT_TOKEN и остальное
set -a; . ./.env; set +a
.venv/bin/python -m suitbot.bot
```

Тесты: `.venv/bin/pip install pytest && .venv/bin/python -m pytest`

## Настройки

Все настройки задаются через переменные окружения, см. `.env.example`.
`GAME_NUMBER_WRAP` — номер, после которого счётчик игр начинается заново.
Проверьте его по своему каналу: от него зависит, на какие игры принимаются ставки.
