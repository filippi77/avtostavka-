# Delivery — приложение курьера (Германия, UPS)

Мобильное веб‑приложение (PWA) для доставки посылок. Интерфейс по умолчанию на **немецком** (переключается на русский в настройках ⚙), распознавание и разбор адресов настроены на немецкие этикетки (DHL, Hermes, DPD, GLS, Amazon), дизайн в стиле iOS.

1. **Сканирование этикетки** — фотографируете посылку камерой телефона, текст распознаётся прямо на устройстве (Tesseract.js; немецкий, по желанию + русский).
2. **Выделение адреса** — формат «Straße Hausnummer / PLZ Ort»: метки *Empfänger / An: / Lieferadresse*, блок *Absender / Abs. / Von:* отбрасывается, поддерживаются Packstation/Postfiliale, c/o, австрийские и швейцарские индексы, адрес в одну строку через запятые или «·». Отдельно извлекаются **имя получателя** (для таблички на звонке) и **телефон** (+49). Русские адреса тоже распознаются как запасной вариант.
3. **Поиск на карте** — геокодирование через OpenStreetMap (Nominatim). Если вариантов несколько — выбираете нужный; если адрес не найден — ставите точку на карте пальцем. Маркеры можно перетаскивать.
4. **Тур** — крупная карточка «Nächster Stopp» с кнопками *Navigieren / Zugestellt / Nicht angetroffen*, ниже компактный список остальных точек с расстоянием и временем, раздел «Erledigt». Кнопка «Hinzufügen & nächstes» позволяет сканировать посылки подряд.
5. **Оптимальный маршрут** — порядок объезда считается по реальному времени в пути (OSRM) от вашего текущего местоположения (GPS), затем улучшается алгоритмами 2‑opt / or‑opt. Если сервер маршрутов недоступен — расчёт по прямым расстояниям.
6. **Навигация** — Apple Karten (по умолчанию на iPhone), Google Maps (весь маршрут до 10 точек) или Waze.

Список хранится в памяти телефона (localStorage) и не теряется при закрытии.

## Быстрый ввод адреса

При ручном вводе под полем появляются подсказки (сервис **Photon**, данные OpenStreetMap) — улицы и дома **в радиусе 50 км** от вашего GPS-местоположения, ближайшие сверху, с расстоянием. Выбрали улицу → дописываете номер дома → выбираете дом: координаты уже известны, можно сразу добавлять. Радиус (10/25/50/100 км) меняется в настройках ⚙. Если подсказок нет — кнопка «Adresse suchen» ищет по всей стране, как раньше.

## UPS

- Распознаются этикетки UPS: «SHIP TO» (в т. ч. «SHIP» / «TO:» в две строки), текст ЗАГЛАВНЫМИ (приводится к обычному виду), отправитель сверху без подписи отбрасывается, телефон берётся только из блока получателя, служебные строки (вес, «1 OF 1», SHP#, маршрутный код) игнорируются.
- **Уровень сервиса** определяется автоматически и задаёт порядок в маршруте: **Express Plus (9:00) → Express (10:30/12:00) → Express Saver → Standard**; внутри каждой группы — самый быстрый порядок. Уровень можно поменять вручную при добавлении/редактировании или кнопкой ⚡. Saver можно приравнять к Standard в настройках.
- **Трек-номер 1Z…** сохраняется у адреса; на карточке видны его последние 4 символа, чтобы быстро найти посылку в машине.

## Android-приложение (APK)

APK собирается автоматически на GitHub при каждом изменении кода и выкладывается в раздел **Releases** репозитория (`delivery-N.apk`).

**Установка:** на телефоне откройте последний релиз в Releases → скачайте `.apk` → откройте файл → разрешите «Установка из неизвестных источников» для браузера/«Файлов» → «Установить». Новые версии ставятся поверх, список адресов сохраняется.

**Живой сканер:** в APK кнопка *Scannen* открывает камеру с распознаванием текста Google ML Kit прямо на телефоне (работает без интернета, распознаёт немецкие ä/ö/ü/ß). Наводите камеру на адресный блок: когда рамка станет зелёной и адрес несколько кадров подряд читается одинаково, телефон вибрирует и адрес подставляется сам. Есть фонарик для тёмного кузова. Кнопка «Text übernehmen» забирает текст вручную.

APK подписан постоянным отладочным ключом (`android/app/avtostavka-debug.keystore`, пароль `android`), чтобы обновления ставились поверх. Для публикации в Google Play нужен отдельный ключ, хранящийся в секретах репозитория.

Локальная сборка (нужны Android Studio / Android SDK и JDK 21):
```bash
npm install
npm run android:sync
cd android && ./gradlew assembleDebug
```

## iPhone / iOS

Работает на iPhone с **iOS 15.4 и новее** (Safari). Проверено и учтено:
- камера через выбор фото (`capture`), GPS, звонок по `tel:`;
- установка на экран «Домой» — приложение подсказывает это само при первом открытии в Safari; после установки открывается без адресной строки, данные сохраняются;
- безопасные зоны (вырез/«чёлка», полоска жестов), шрифт SF, тёмная тема, без зума при вводе;
- навигация открывает приложение Apple Karten (оно принимает одну точку — ведёт к следующему адресу);
- нет конструкций JavaScript, которые ломают старые версии Safari.

Ограничения iOS для веб‑приложений: нет фонового режима и push‑уведомлений по геопозиции, сканирование — через снимок фото, а не «живой» видоискатель. Если это станет важно — тот же код упаковывается в нативное приложение через Capacitor и публикуется в App Store (нужен Mac и аккаунт Apple Developer, 99 $/год).

## Установка на телефон

Камера и GPS в браузере работают только по **HTTPS**, поэтому приложение нужно разместить на хостинге. Проще всего — GitHub Pages:

1. Влейте код в ветку `main`.
2. В репозитории: **Settings → Pages → Build and deployment → Source: GitHub Actions**.
3. После деплоя откройте адрес вида `https://<логин>.github.io/avtostavka-/` на телефоне.
4. **iPhone (Safari):** «Поделиться» → «На экран „Домой“».
   **Android (Chrome):** меню ⋮ → «Установить приложение».

Приложение откроется во весь экран, как обычное.

## Локальный запуск

```bash
npm start      # http://localhost:8080 (на localhost камера тоже работает)
npm test       # тесты разбора адресов и оптимизации маршрута
```

Сборка не нужна — это статические файлы.

## Советы по сканированию

- Снимайте этикетку ровно, крупно, при хорошем освещении — блок адреса должен занимать бо́льшую часть кадра.
- Первое распознавание дольше (загружается модель ~15 МБ), дальше она берётся из кэша.
- Включите «Automatisch hinzufügen…» в настройках, чтобы однозначно найденные адреса добавлялись без лишних нажатий.
- Для этикеток на русском выберите «Sprache der Etiketten → Deutsch + Russisch».

## Ограничения бесплатных сервисов

Используются публичные серверы OpenStreetMap (подложка карты — tile.openstreetmap.de, при сбое — tile.openstreetmap.org): Nominatim (не чаще 1 запроса в секунду) и демо‑сервер OSRM (до ~100 точек). Для рабочей нагрузки многих курьеров их стоит заменить на собственные инстансы или коммерческие API (Google, HERE, Mapbox) — это меняется в `js/geocode.js` и `js/route.js`.
