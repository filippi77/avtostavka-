# Формат сигналов 21 очко для автоставки

Бот «Влад» пишет в частный канал «21 очко Авто», где оба бота — админы.
Каждое сообщение — одна строка `AUTO21 <команда> ключ=значение ...`.
Остальной текст в канале автоставка игнорирует.

## Ставка

Отправляется сразу после результата раунда `game - 1`, до начала раунда `game`.

```
AUTO21 BET sig=541 game=543 out=G step=2 max=10 kf=50
```

| ключ | что это |
|------|---------|
| `sig`  | номер сигнала (цепочки), одинаковый у всех её шагов |
| `game` | номер раунда `#N`, НА КОТОРЫЙ ставим |
| `out`  | исход: `O` — 21 очко, `G` — Голд, `R` — Раздача, `X` — Ничья, `P4` — 4 карты игроку |
| `step` | шаг догона (1, 2, 3…) |
| `max`  | сколько всего шагов в цепочке |
| `kf`   | ожидаемый коэффициент (если на сайте сильно другой — не ставим) |

Сумму ставки считает автоставка по своим настройкам для шага `step`.

## Результат раунда

```
AUTO21 RESULT sig=541 game=543 out=G win=1
```

`win=1` — исход выпал, цепочка закрыта; `win=0` — не выпал, дальше будет следующий `BET`
(или конец, если `step = max`).

## Отмена

```
AUTO21 STOP sig=541
```

Цепочка закрывается, следующих ставок по ней не будет.

## Лесенки догона (10 шагов, последний шаг — максимум сайта)

| шаг | Голд (КФ ~47, макс 970) | Раздача (КФ ~13.3, макс 3650) |
|-----|------|---------|
| 1 | 25 | 95 |
| 2 | 40 | 140 |
| 3 | 60 | 215 |
| 4 | 85 | 320 |
| 5 | 130 | 480 |
| 6 | 190 | 720 |
| 7 | 290 | 1080 |
| 8 | 430 | 1620 |
| 9 | 650 | 2430 |
| 10 | 970 | 3650 |
| всего | 2 870 | 10 750 |

Если лимит в купоне («до X ₽») меньше ставки шага — ставится лимит.
