# autobet_bot.py — автоставки на DB Bet через Opera

Telegram-бот: читает сигналы из каналов (теннис Лига Про, FIFA-пенальти) и ставит
через Opera, подключаясь к ней по CDP (`http://127.0.0.1:9222`) с помощью Playwright.
Ставки по системе догона (множитель и число шагов задаются в боте).

## Запуск

1. `pip install pyTelegramBotAPI playwright`
2. Скопировать `autobet.env.example` в `autobet.env` и заполнить токен, ID админа,
   логин/пароль сайта.
3. Запустить Opera с портом отладки 9222, затем `python autobet_bot.py`.

## Вкладки

Бот держит одну вкладку DB Bet. Лишние вкладки DB Bet и страницы ошибок он закрывает
сам (`CLOSE_EXTRA_TABS = True`). Если смотришь сайт вручную в соседней вкладке,
поставь `CLOSE_EXTRA_TABS = False` — тогда закрываются только упавшие.
