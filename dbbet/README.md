# autobet_bot.py — автоставки на DB Bet через Opera

Telegram-бот: читает сигналы из каналов (теннис Лига Про, FIFA-пенальти) и ставит
через Opera, подключаясь к ней по CDP (`http://127.0.0.1:9222`) с помощью Playwright.
Ставки по системе догона (множитель и число шагов задаются в боте).

## Запуск

1. `pip install pyTelegramBotAPI playwright`
2. Скопировать `autobet.env.example` в `autobet.env` и заполнить токен, ID админа,
   логин/пароль сайта.
3. Запустить Opera с портом отладки 9222, затем `python autobet_bot.py`.

## Вкладки

Бот держит одну вкладку DB Bet. Лишние вкладки DB Bet и страницы ошибок он закрывает
сам (`CLOSE_EXTRA_TABS = True`). Если смотришь сайт вручную в соседней вкладке,
поставь `CLOSE_EXTRA_TABS = False` — тогда закрываются только упавшие.

## 🃏 21 очко

Третья игра. Сигналы `AUTO21` (формат — `SIGNAL21.md`) приходят в отдельный канал,
где бот — админ. Когда придёт первый пост, бот предложит кнопку «🃏 Это канал 21 очко».
Бот находит в поиске игру «21 Очко» по номеру, жмёт «Да» в рынке
«Будет "золотое очко"» (Голд) или «Игра завершится на раздаче» (Раздача) и ставит сумму
шага из лесенки `G21_LADDERS`; если лимит в купоне меньше — ставит лимит.

- `/limit 15000` — дневной стоп-лосс должен вмещать лесенку (Голд 2 870 ₽, Раздача 10 750 ₽).
- `/vbank 20000` — виртуальный банк для сухого режима.

## Свой браузер вместо Opera

`/browser own` — бот сам запускает Chromium с отдельным профилем (`browser_profile/`
рядом со скриптом), в мобильной версии сайта, и сам перезапускает его, если тот завис.
`/browser opera` — вернуться к Opera по порту отладки.

- Один раз установить Chromium: `python -m playwright install chromium`.
- VPN: либо VPN-программа на весь компьютер, либо прокси только для браузера бота —
  `AUTOBET_PROXY=socks5://логин:пароль@хост:порт` в `autobet.env`.
